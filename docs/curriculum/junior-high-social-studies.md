# 中学校 社会（中1〜中3）— 学習範囲・教材制作マップ

- 対象：平成29年告示の中学校学習指導要領（2021年度全面実施）。確認日：2026-10-24。
- 目的：学習アプリの単元設計・問題設計・教材制作のための独自整理。公式の内容項目と、編集上の単元分割・例題を区別する。
- 必修範囲：地理的分野・歴史的分野・公民的分野。人物名や地名の暗記だけでなく、資料を読み、関係を説明し、根拠に基づき考察する力を扱う。
- 表の「項目」は学習指導要領との対応。「到達目標」「問題・教材例」はアプリ向けの編集案であり、文科省が指定した設問ではない。IDはこの資料群の管理用。

## 1. 学年配当と授業時数

**公式の原則**：中1・中2は地理と歴史を並行して学習し、中3は歴史と公民を学習する。3年間の分野別配当は地理115、歴史135、公民100単位時間。学校教育法施行規則の標準授業時数は中1が105、中2が105、中3が140、計350単位時間（1単位時間50分）。[S1 第2章第2節・第3の1(3)、印刷p.63／S2 第3章1、付録1 p.194]

**以下は編集上の標準配当例であり、各単元の学年を全国一律に固定するものではない。** 学校・教科書の年間計画に合わせて変更できるよう、アプリは学年と単元を別々に管理する。特に「中3＝公民のみ」としない。

| 学年 | 編集上の配当例 | 留意点 |
|---|---|---|
| 中1 | 地理：世界と日本の地域構成、世界の生活・諸地域。歴史：導入、古代、中世 | 地理・歴史を並行。地域調査や歴史調査は他の単元と組み合わせられる |
| 中2 | 地理：日本の特色・諸地域・地域の在り方。歴史：近世、近代の成立〜明治期など | 歴史の区切りは学校により異なる。地理はA→B→Cの構成順を踏まえる |
| 中3 | 前半に歴史の続き（近現代）、その後に公民 | 「前半」は編集上の例。公式指定は中3に歴史と公民を置くことであり、月単位の境界ではない |

公民のB（経済）とC（政治）は内容の関連を踏まえ順序を工夫できる。下表は公式項目順であり、教材のリリース順ではない。

### 地理で省略しない条件

- 世界の諸地域は6州を扱う。表の主題は編集例で、各州の特徴に合う**異なる地球的課題**を設定する。州内を均一とみなさず地域差・変化を扱う。
- 日本の7地方区分は教材制作上の一般的な例。学習指導要領は学校の事情等に応じた地域区分を認めている。日本の諸地域では「自然環境」「人口や都市・村落」「産業」「交通や通信」を中核とする考察を、それぞれ少なくとも一度は扱う。その他の事象を中核にすることもできる。
- 領域は指導要領の内容の取扱いに沿い、北方領土・竹島についての日本の立場、尖閣諸島についての日本の立場を扱う。教材では「日本政府の立場」と出典を明示し、関係国の主張や現状を扱う場合は事実と主張を区別する。出題の正答を曖昧な「世界共通の認識」にしない。
- 地図問題には縮尺・凡例・方位・基準年を付ける。統計の順位・人口・国際組織の加盟状況は更新対象とし、出典年と取得日を保存する。

### 歴史を教材化する際の軸

- 各時代の最後に「政治・生産・社会・文化・対外関係」のつながりをまとめ、前の時代との連続・変化を説明させる。年号暗記の正答率だけで時代理解を判定しない。
- 史料の作者、成立時期、目的、立場を確認する。記述された事実、作者の評価、学習者の推論を区別する。資料1点から社会全体を断定させない。
- 中近世の対外関係、近代の植民地支配・戦争、差別、戦後の社会変化などを省略せず、確認できる事実と歴史的解釈を区別する。歴史上の政策の影響は複数の立場から扱う。
- A(2)の地域調査は導入1回で終わらせず、学習する時代とつなぐ。近現代は中3の公民へつながる重要範囲として制作時間を確保する。

### 公民で扱う事例の注意

憲法・選挙・契約・税・労働・社会保障を教材にする際、制度の細部は制作時点の一次資料で再確認する。このファイルは現行制度の詳細を確定する法務資料ではない。実際の税率や年齢要件等を使う問題には基準日を付ける。領土・安全保障・国際情勢では、教材中の事実、政府等の立場、学習者が評価する論点を区別する。特定の政治的結論への賛否を点数化せず、根拠・論理・異なる立場への検討を評価する。

## 5. 横断的な技能・誤概念・制作着手案

| 技能・典型的な誤概念 | 教材に入れる支援 | 確認方法 |
|---|---|---|
| 地図で広く見える地域ほど実面積も大きい | 地球儀と異なる地図表現の比較 | どの資料で比較できるかを選び理由を述べる |
| 気候だけで生活・産業が決まる | 自然・歴史・技術・政策の複数資料 | 同じ気候で生活が異なる例を説明する |
| 統計の相関がそのまま因果関係になる | 総数と割合、母集団、単位、別の原因の確認 | グラフから言えること・言えないことを分ける |
| 同時代の人々は皆同じ生活・考えだった | 地域・身分・性別・職業等の異なる史料 | 共通点と違いを区別して説明する |
| 鎖国は海外との交流が完全にゼロ | 時期別の窓口・相手・交流内容の地図 | 制限と継続した交流を両方説明する |
| 多数決なら常に公正 | 手続、基本的人権、少数意見の検討 | 結論だけでなく決め方を評価する |
| 公正は常に全員同じ負担、税は損失だけ | 条件の違いと公共サービスを示す | 立場別の利点・負担を比較する |

制作の第一巡では、各IDについて「短い概念教材」「資料読解」「理由説明」「振り返り」を1組にする。単語選択だけで完結させない。自由記述は、事実の正確さ・資料の利用・因果や比較の論理・反対資料への配慮を分けて採点する。社会への関心や政治的な価値観を、クリック数や特定回答への同意だけで判定しない。

# ひび学習

高校生の家族向け学習PWA。古文・漢文・英語の写真やPDFを保護者が追加し、AIが作った問題を確認・承認してから公開します。生徒は毎日の10問と追加練習で学び、間違えた問題を日を空けて復習できます。

## できること

- 写真・PDFから問題集を作成。目標10〜300問、1回20資料まで。資料不足の水増しを避けるため、実際の問題数は目標より少なくなることがあります。
- 原本・根拠・選択肢・正答・解説の確認、編集、承認、公開予約。
- 毎日の10問、追加10問、苦手問題、問題集の選択。
- 回答日時、最終回答、誤答回数、正答率、次回復習の記録。
- 1・3・7・14・30日の復習間隔。同日中の解き直しや早すぎる復習で習熟度を水増ししません。
- 保護者の学習状況画面。出題率、初回正答率、別日の復習正答率、日別活動、苦手問題。
- Googleログインと家族の許可リスト。ホーム画面への追加、任意の新規公開通知。

## 構成

| 役割 | 保存・実行先 |
| --- | --- |
| iPhone / 保護者画面 | Next.js・ReactのPWA、Vercel |
| 教材の写真・PDF | 保存用GoogleアカウントのDrive、アプリ専用フォルダ |
| 問題・回答・出題履歴 | 同じアカウントのGoogle Sheets、追記専用Eventsタブ |
| ログイン | Google OAuth、サーバー側の家族許可リスト |
| 読み取り・作問 | Claude API、Vercel Workflowで分割実行 |
| お知らせ | Web Push。通知の成否と問題公開は独立 |

生徒の端末や保護者のMacを常時起動する必要はありません。Driveの利用権限はサーバーだけが持ち、生徒のログインにはDriveアクセスを要求しません。

Sheetsは少人数の家族用です。全イベントの再読込方式なので、大人数・大量の長期記録には専用DBへの移行が必要です。追記の重複はイベントIDで除き、最初の回答を採用します。出題時の問題を固定保存するため、後日の編集で採点は変わりません。

## ローカルで確認

Node.js 24を使います。

```sh
npm ci
npm run dev
```

`http://127.0.0.1:3000/?demo=1` は明示的なデモです。サンプル問題・履歴をブラウザに保存し、生徒と保護者を切り替えられます。デモではAI通信・家族間同期・プッシュ通知は実行しません。写真はこのブラウザのIndexedDBにだけ保存されます。

通常の `/` は本番ログイン用です。設定不足時は実データへのアクセスを拒否します。

```sh
npm test
npm run test:server
npm run typecheck
npm run build
```

## 本番セットアップ

1. VercelでこのリポジトリをNext.jsプロジェクトとして登録し、Node.js 24を選択します。
2. [Google接続の手順](docs/GOOGLE_SETUP.md)に沿って、Google OAuthクライアントと教材・記録の保存先を設定します。
3. `.env.example`の値をVercelのEnvironment Variablesに設定します。秘密情報をリポジトリやチャットに貼らないでください。ローカルで接続を試す場合だけ`.env.local`に保存します。
4. Googleのリダイレクト先を `https://本番ドメイン/api/auth/callback/google` に設定します。`NEXTAUTH_URL`と`NEXT_PUBLIC_APP_URL`も同じ本番URLにします。
5. 家族のGoogleメール、表示名、役割を`ALLOWED_FAMILY_MEMBERS_JSON`に設定します。空の設定は誰もログインできません。
6. Claudeのキーと明示的なモデル名、利用予算を決めてから`AI_GENERATION_ENABLED=true`を設定します。初期値は`false`です。
7. 必要ならVAPIDキーを作成して通知を設定します。iPhoneではSafariからホーム画面に追加してから通知を許可します。

VercelのPreviewとProductionで保存先や認証情報を分けてください。プレビューに本番の家族データを接続しないでください。環境変数の変更後は再デプロイが必要です。

## 費用と保存範囲

AIによる読み取り・作問はClaude APIの従量料金がかかります。作成済み問題の採点・復習にはAIを呼びません。ジョブ上限は初期値1日3回・月10回で、1回最大300問です。これは金額の上限ではありません。Claudeアカウント側にも利用上限を設定し、少量の教材で実費を確認してから増やしてください。障害後の再依頼で再課金される場合があります。

Vercel・Googleの既存プラン、使用量、保存容量、最新の各サービスの条件も適用されます。アプリはプラン変更や支払い登録を自動で行いません。

写真は端末上で長辺2400px以内のJPEGに調整し、位置情報などのEXIFを含めず送信します。アップロードするコピーは元写真と異なります。画像の判読性はレビューで確認してください。PDFは1件10MBまで。HEICはブラウザが読み込める場合に変換し、非対応ならJPEGでの保存を案内します。

Claudeへ送るのは教材と作問に必要な問題内容です。回答履歴や家族のメールは送信しません。AIの正解は保証されないため、すべて保護者の承認が必要です。

## 安全性と運用

- 生徒には未回答の正答・解説・原本・出題時の解答付きスナップショットを送信しません。採点はサーバー側で行います。
- 設定済みの家族・役割・Googleの確認済みメールを毎回検証します。
- Googleのアクセストークン、リフレッシュトークン、Claudeキーはブラウザに渡しません。
- 原本は保護者専用APIで取得します。Driveの「リンクを知っている全員」共有は不要です。
- アップロード先は特定ファイル専用の一時URLです。このURLも第三者へ共有しないでください。
- 学習データをService Workerにキャッシュしません。オフラインでは接続の案内を表示します。
- 元のEventsタブは並べ替え・手動編集せず、バックアップ用コピーを取ってください。学習記録は管理者のGoogle Driveでもアクセス管理が必要です。
- 保護者の「書き出す」はJSONのデータ出力です。写真・PDF本体は含みません。

実Googleアカウントでのアップロード・共有、実Claudeによる教材精度、実機iPhoneの通知は、接続設定後に確認が必要です。ローカルのテストとデモ画面の検証は、この実接続確認の代わりにはなりません。

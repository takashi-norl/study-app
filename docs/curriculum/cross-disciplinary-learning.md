# つながりで学ぶ — 科学技術史と教科横断の学習メニュー

作成日：2026-10-24。ユーザー要望「科学技術の発展と歴史を横断的に学ぶ教材」「知識体系を有機的に結合するメニュー」を、教材・画面・学習記録の設計に落とした初版。**教材準備とメニュー構想であり、アプリへの実装・配信は未実施。** 数学のアプリ化・作問は引き続き保留。

## 1. 目指す学び

例えば蒸気機関を学ぶとき、「熱を仕事へ変える仕組み」「石炭や鉱山という条件」「工場や交通への利用」「働き方や環境への影響」をつなげて考える。出来事と用語を並べるだけでなく、**なぜ関係するのか、どんな条件なら成り立つのか、何を根拠に言えるのか**を説明できる教材にする。

中学知識で入り、高校の内容へ深掘りできる。大人の学び直しでも使えるよう、学年を入口の条件にしない。「まずわかる」「深く考える」を選び、必要な前提知識は短い補助教材で確かめる。

既存の教科別教材は学習範囲の台帳として使い、このメニューを別の入口として重ねる。1つの概念や問題を複数コースから参照できるようにし、同じ単元を複製して進捗を二重に計上しない。

## 2. メニューの入口

画面上の名前は **「つながりで学ぶ」**。その中に3つの入口を置く。以下は表示例で、実装済みの画面ではない。

| 入口 | 学習者が選ぶもの | 画面に見せること | 最初の題材 |
| --- | --- | --- | --- |
| 物語から | 変化の過程をたどるコース | 中心の問い、章の順序、扱う時代・地域、学べること | 蒸気機関は、なぜ社会を変えた？ |
| つながりから | いま知りたい概念・出来事 | 選んだ知識、その周囲の3〜5件、関係の説明 | 蒸気機関→熱／鉱山と石炭／工場と交通／労働／環境 |
| 問いから | 身近な疑問や比較課題 | 考えるための手掛かり、複数の見方、最後に作る説明 | 便利な技術が広がると、誰の暮らしが変わる？ |

「教科から学ぶ」と相互に移動できる。例：電磁誘導の単元末から「この原理は発電や送電にどう使われた？」へ進み、科学技術史のコースから「電磁誘導の仕組みを確認する」へ戻る。

ホームに多数の新メニューを増やすより、まず共通教材の入口にこの1つを置く案を優先する。既存画面への配置はアプリ担当が現在の導線と照合して決める。

## 3. 物語から：出来事を一本の必然にしない

コース候補は[教科横断コース案](integrated-courses.md)。1コースでは次の要素を扱うが、全てを同じ順序に固定しない。

| 要素 | 学習者の問い | 教材に必要なもの |
| --- | --- | --- |
| 人々の課題と既存の手段 | 当時の人は何に困り、どう対処していたか | 地域・時期・立場、先行する方法 |
| 原理と観測 | 何が起きるのか、どう確かめられるのか | 図やデータ、条件、科学概念への接続 |
| 改良と実用化 | 原理が分かるだけで使えるようになるか | 材料、加工、費用、故障、技能、複数の担い手 |
| 普及の条件 | どこで、誰が、なぜ使ったのか | 資源、交通、需要、投資、制度、地域差 |
| 社会との相互作用 | 生活・産業・権利・環境はどう変わったか | 利益と負担、技術以外の要因、反例 |
| 比較と現在の問い | 他の時代・技術でも同じことが言えるか | 比較する条件、似ている点と違う点 |

科学的発見、発明、特許、改良、実用化、普及は別の出来事として扱う。発明年だけで社会全体の変化を説明しない。時間軸に同時代の複数地域を置き、伝播・翻訳・交易・制度の働きを扱う。「偉人が一人で世界を変えた」「新技術は必ず社会をよくする」という結論を前提にしない。

各章の終わりには「次の章」「原理を確かめる」「別の地域・時代と比べる」を置く。寄り道後は元の章へ戻れるよう、コース名・現在章・戻る先を保持する。

## 4. つながりから：関係を言葉にする

[知識の接続設計](knowledge-connections.md)を正本とする。初期版は全知識を一度に描いた巨大な図にせず、選んだ知識を中心に近い関係だけを見せる。

- 「仕組みを知る」：蒸気機関と熱・仕事など、原理を説明する関係。
- 「当時の背景を知る」：資源・需要・制度など、成立・普及を考える関係。
- 「何が変わったか」：影響を調べる関係。時期・地域・他の要因を一緒に見せる。
- 「比べて考える」：同じ働き・異なる条件を比較する関係。
- 「根拠を読む」：史料、観測、模型、統計など、説明を検討する関係。

どの関係にも短い説明を付ける。「関連あり」だけのリンクは作らない。学習上の前提関係と歴史上の因果関係を同じ矢印で表示しない。例えば「熱を学ぶと蒸気機関の仕組みを説明しやすい」は学習の接続であり、「熱力学の完成が先にあったから蒸気機関が発明された」という歴史の主張ではない。

既習ではない概念には「ここを確認すると分かりやすい」を示すが、探索自体を止めない。前提確認の短い説明と、元の教材へ戻る操作を用意する。知識の地図と同じ内容を、読み上げ・小画面でも使える一覧として提供する。

## 5. 問いから：知識を別の場面で使う

問いは、答えを出すために複数の知識を使う課題にする。単なる雑学クイズや、根拠のない自由感想で終わらせない。

| 問いの例 | 使う視点 | 最後に残すもの |
| --- | --- | --- |
| 動力が変わると、工場を置く場所はどう変わり得るか | 動力源、資源、輸送、人手、市場 | 条件付きの立地比較。動力だけでは決まらない点を含む |
| 発電できれば、誰でも同じように電気を使えるか | 電磁誘導、送電、インフラ、費用、地域差 | 原理と普及条件を分けた関係図 |
| 病気の仕組みが分かれば、流行はすぐなくなるか | 微生物、検証、上下水道、制度、利用可能性 | 原理・証拠・対策・実行条件を区別した説明 |
| 情報を遠くへ速く送れると、信頼性も上がるか | 通信、報道、出典、検証、権利 | 伝達速度と情報の確かさを分けた資料比較 |
| エネルギーを選ぶとき、何を比べればよいか | 変換、供給条件、費用、環境、社会的合意 | 利点・負担・不確実性を示す比較表 |

問いへの賛否を正解にしない。評価するのは、原理が適切か、資料を使っているか、複数の条件・立場を分けたか、説明の限界に気付けたかである。

## 6. 1回の学習と、時間を置いた再訪

編集上の目安として、1回は短い章と確認問題を中心にする。時間を固定したり、全員が同じ所要時間で理解できると表示したりしない。

1. 問いを見て、今の予想を選ぶ。
2. 原理・背景・証拠を短い教材で読む。
3. 必要なら関連単元へ寄り道して戻る。
4. 条件・根拠を使う問題に答える。
5. 最初の予想を見直し、「何と何が、どう関係するか」を説明する。
6. 後日、別の技術や地域の事例で同じ観点を使う。

履歴は「読んだ章」「単元の確認問題」「関係を説明する課題」を分ける。閲覧回数や地図を広げた数を習得率にしない。既存問題と同じIDを参照したときは、既存の学習記録との重複を避ける。復習時には同じ文章の記憶だけで答えられない比較課題を用意する。

## 7. 科目への接続

| 科目 | 横断教材での役割 | 扱い |
| --- | --- | --- |
| 理科 | 観測・実験、物質・エネルギー・生命・地球の原理 | 正確な概念と適用条件を確認する |
| 社会 | 時代・地域、産業・交通、制度・権利、国際関係 | 技術が使われる条件と社会との相互作用を捉える |
| 国語 | 史料・説明文・論証の読解、要約、比較、説明 | 本文根拠と推論を区別して書く |
| 英語 | 出典の短い原文、説明・比較・発信 | 意味の補助を付ける任意の深掘り。英語力をコース入口の条件にしない |
| 数学 | 必要な量・比例・グラフの読み方 | 今回は教材内の補助説明まで。独立した数学作問・入力・採点機能は保留 |

この分類は編集上の接続であり、横断コース1本の完了が対応する全科目・全単元の習得を意味するわけではない。

## 8. 最初の制作範囲とアプリ担当への引き継ぎ

最初の完成対象を、[蒸気機関の試作](science-history-pilot.md)1本に絞る。次は電気・送電と医療・衛生を候補とし、3本の間で同じ関係の見方を再利用できるかを確認する。10本のコース案を完成済み教材として数えない。

| 今回用意したもの | 次に必要な作業 |
| --- | --- |
| 3つの入口、画面遷移と評価の方針 | アプリの既存導線との配置調整 |
| 10本の編集コース案 | 小目標・章・資料・問題の詳細化と内容確認 |
| 具体的な関係の例と保存項目案 | 根拠と向きの編集、参照先の検証、実データ形式の確定 |
| 蒸気機関1教材・3問の原稿。別のAI担当による解き直し済み | 人による専門レビュー、学習者での試用、取込用変換 |

現行の四択問題集取込形式は、コースの章、概念間の関係、史料の位置、関係説明課題を専用項目として保存できない。原稿は[制作設計](authoring-plan.md)の共通項目に加えてコース・接続情報を別に保持し、現在の厳密な取込形式へ未知の項目を追加して送らない。

アプリ側の初期実装は、コース一覧→章→関連教材3〜5件→元の章へ戻る、という経路で試す。地図の描画そのものより、関連の理由・文脈・戻り道が実際に役立つかを先に確認する。確認条件は、同じ問いを複数科目の根拠で説明できること、未履修でも補助説明から復帰できること、関連を閲覧しただけで習得済みにしないこと。

## 9. 出典と確認の方針

この文書のメニュー・構成・課題は編集上の提案であり、文科省指定の学習順ではない。教科範囲の根拠は[公式出典一覧](sources.md)。歴史的事実の個別根拠は[コース案](integrated-courses.md)と[試作原稿](science-history-pilot.md)に記録する。科学的な原理の説明、歴史的な因果の主張、学習用に設けた関係・問いを分けて確認する。

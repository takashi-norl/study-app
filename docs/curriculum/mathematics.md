# 数学 — 中1〜高3の公式範囲の概要（調査のみ・開発保留）

確認日：2026-10-24。中学校は平成29年告示、高校は平成30年告示の学習指導要領に基づく。数学は参考用の範囲調査にとどめ、今回のアプリ化・作問・実装計画の対象から外す。

## 1. 中学校：学年ごとの範囲

A＝数と式、B＝図形、C＝関数、D＝データの活用。学年配当は公式。標準授業時数は中1が140、中2が105、中3が140単位時間（1単位時間50分）。[M1 第2章第3節／M2 第3章第1〜3節、付録1]

| 学年 | 分野 | 公式内容項目と主な範囲 |
|---|---|---|
| 中1 | A 数と式 | (1)正の数・負の数、四則計算、自然数を素数の積で表すこと。(2)文字を用いた式、一次式の加減、数量関係の表現。(3)一元一次方程式、比例式、具体的な場面での活用 |
| 中1 | B 図形 | (1)平面図形、基本的な作図、平行移動・対称移動・回転移動。(2)空間図形、直線・平面の位置関係、立体の見取図・展開図・投影図、表面積・体積 |
| 中1 | C 関数 | (1)関数関係、比例・反比例、座標、表・式・グラフを関連付けた理解と活用 |
| 中1 | D データの活用 | (1)ヒストグラム・相対度数、データの分布と傾向の読取り、批判的な考察。(2)多数回の試行を基にした確率の必要性と意味 |
| 中2 | A 数と式 | (1)文字式の四則計算、数量関係の説明、目的に応じた式変形。(2)二元一次方程式と連立二元一次方程式、解法と活用 |
| 中2 | B 図形 | (1)平行線・角・多角形の性質。(2)三角形の合同条件、図形の性質の証明、二等辺三角形・平行四辺形等、仮定と結論、逆・反例 |
| 中2 | C 関数 | (1)一次関数、変化の割合、表・式・グラフ、二元一次方程式のグラフ、事象のモデル化と活用 |
| 中2 | D データの活用 | (1)四分位範囲・箱ひげ図、複数集団の比較。(2)場合の数を基にした確率、同様に確からしいこと、簡単な場合の確率 |
| 中3 | A 数と式 | (1)平方根、有理数・無理数、根号を含む計算。(2)式の展開と因数分解。(3)二次方程式、因数分解・平方の形・解の公式、活用。誤差・近似値等も扱う |
| 中3 | B 図形 | (1)相似、三角形の相似条件、平行線と線分比、相似比と面積比・体積比。(2)円周角と中心角。(3)三平方の定理と活用 |
| 中3 | C 関数 | (1)関数 y＝ax²、表・式・グラフの関係、変化・比較、事象への活用。いろいろな事象と関数も扱う |
| 中3 | D データの活用 | (1)標本調査、母集団と標本、標本を用いる意義、母集団の傾向の推定、調査方法・結果の吟味 |

全学年で、問題の発見・解決・説明・対話・振り返りを含む数学的活動を扱う。

## 2. 高校：必履修・選択・履修順

高校は**科目別の規定**であり、高1・高2・高3に全国一律の内容を割り当てていない。数学Ⅰが必履修。数学Ⅱ・Ⅲ・A・B・Cを全員必履修としない。[M3 第1章第2款3、第2章第4節第3款]

| 科目 | 標準単位数 | 履修条件・選択の扱い |
|---|---:|---|
| 数学Ⅰ | 3 | 必履修。特に必要がある場合は総則の条件に基づき2単位にできる |
| 数学Ⅱ | 4 | 履修させる場合、原則として数学Ⅰの後 |
| 数学Ⅲ | 3 | 履修させる場合、原則として数学Ⅰ→Ⅱ→Ⅲの順 |
| 数学A | 2 | 数学Ⅰと並行、またはⅠの後。内容(1)〜(3)から適宜選択 |
| 数学B | 2 | 原則として数学Ⅰの後。内容(1)〜(3)から適宜選択 |
| 数学C | 2 | 原則として数学Ⅰの後。内容(1)〜(3)から適宜選択 |

A・B・Cは科目内でも内容を選択するため、下表の全内容が全履修者に共通するわけではない。実際の単位数は学校の計画で確認する。

学年への置き方の**例**は、高1で数学Ⅰ（＋A）、高2で数学Ⅱ（＋B・Cの一部）、高3で必要に応じ数学Ⅲ・C等。公式の学年指定ではない。Cを必ずBの後に履修するという規定でもない。

## 3. 高校：科目別の全大項目

根拠：M3 第2章第4節第2款、第1〜第6。M4 第1章の科目内容一覧（印刷pp.15–16）、第2章各科目の解説。

| 科目 | 公式大項目 | 主な範囲 |
|---|---|---|
| 数学Ⅰ | (1)数と式 | 実数、集合と命題、式の展開・因数分解、一次不等式 |
| 数学Ⅰ | (2)図形と計量 | 三角比、正弦定理・余弦定理、図形の長さ・角度・面積等 |
| 数学Ⅰ | (3)二次関数 | グラフ、最大・最小、二次方程式・二次不等式との関係 |
| 数学Ⅰ | (4)データの分析 | 分散・標準偏差、散布図・相関係数、仮説検定の考え方 |
| 数学Ⅱ | (1)いろいろな式 | 多項式・分数式、二項定理、等式・不等式の証明、複素数と二次方程式、高次方程式 |
| 数学Ⅱ | (2)図形と方程式 | 座標、直線・円の方程式、軌跡、領域 |
| 数学Ⅱ | (3)指数関数・対数関数 | 指数の拡張、指数・対数とその関数、性質・グラフ・活用 |
| 数学Ⅱ | (4)三角関数 | 一般角・弧度法、三角関数、加法定理等 |
| 数学Ⅱ | (5)微分・積分の考え | 微分係数・導関数、増減・極値、不定積分・定積分、面積 |
| 数学Ⅲ | (1)極限 | 数列の極限、無限等比級数、分数・無理関数、合成・逆関数、関数の極限 |
| 数学Ⅲ | (2)微分法 | 積・商・合成関数、三角・指数・対数関数の微分、接線・増減・凹凸、速度・加速度 |
| 数学Ⅲ | (3)積分法 | 不定・定積分、置換積分・部分積分、面積・体積・曲線の長さ |
| 数学A | (1)図形の性質 | 三角形・円、作図、空間図形の性質 |
| 数学A | (2)場合の数と確率 | 数え上げ、順列・組合せ、確率の基本法則、独立試行、条件付き確率、期待値 |
| 数学A | (3)数学と人間の活動 | 数量・図形と文化・歴史・遊びのつながり、ユークリッドの互除法、二進法、位置の表現等 |
| 数学B | (1)数列 | 等差・等比数列、和、いろいろな数列、漸化式、数学的帰納法 |
| 数学B | (2)統計的な推測 | 確率変数・分布、二項分布・正規分布、母集団・標本、区間推定、仮説検定 |
| 数学B | (3)数学と社会生活 | 社会の事象の数学化、モデル・データによる問題解決、結果の評価・改善 |
| 数学C | (1)ベクトル | 平面・空間のベクトル、演算・内積、空間座標、図形への活用 |
| 数学C | (2)平面上の曲線と複素数平面 | 二次曲線、媒介変数・極座標、複素数平面、ド・モアブルの定理 |
| 数学C | (3)数学的な表現の工夫 | 図・表・統計グラフ、離散グラフ、行列による事象の表現と考察 |

現行ではベクトル・複素数平面・平面上の曲線は数学C。数学Ⅰの仮説検定の考え方と数学Bの統計的推測は深さが異なる。

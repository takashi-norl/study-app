# 中学・高校5教科のカリキュラムと教材制作の準備

確認日：2026-10-24（日本時間）／対象：中学1〜3年・高校1〜3年。文部科学省の学習指導要領本文と教科別解説を基にした、ひび学習の教材制作用の整理です。社会・理科は詳細な単元表と制作準備、英語・国語は追加の範囲調査、数学は範囲の概要を収録しています。科学技術と歴史を横断するコース、知識のつながりをたどるメニューも設計しています。数学のアプリ化・作問準備は保留です。

## 適用する学習指導要領

- 中学校：平成29年告示。2021年度から全面実施。
- 高等学校：平成30年告示。2022年度入学生から年次進行で実施。
- 本文だけで判断しづらい学習範囲・扱い方は、確認日に公式一覧からリンクされていた解説で補っています。告示年とPDFの更新日を区別します。
- 次期改訂に向けた審議資料は、現在の学習範囲には混ぜません。適用課程を変更する場合は新しい版として管理します。

根拠：[文科省・本文と解説](https://www.mext.go.jp/a_menu/shotou/new-cs/1384661.htm)、[政府広報・実施時期](https://www.gov-online.go.jp/article/201903/entry-8992.html)。詳細は[出典一覧](sources.md)。

## 学年別に見る入口

以下は検索・学習プランのための見取り図です。中学社会の細かな区切り、高校の科目配当は**編集上のモデル**で、全国共通の指定ではありません。中学理科の大項目の学年指定、社会の分野配当、高校の履修順の制約は各ファイルに分けて記しています。

| 学年 | 社会の入口 | 理科の入口 |
| --- | --- | --- |
| 中1 | 地理と歴史を並行。世界の地域、歴史の調べ方・古代〜中世を中心とするモデル | 身近な物理現象、身の回りの物質、生物の観察と分類、大地の成り立ちと変化 |
| 中2 | 地理と歴史を並行。日本の地域、近世〜近代を中心とするモデル | 電流、化学変化と原子・分子、生物の体のつくりと働き、気象 |
| 中3 | 歴史の現代までを学び終えて公民へ。人権・政治・経済・国際社会 | 運動とエネルギー、イオン、生命の連続性、地球と宇宙、自然・科学技術と人間 |
| 高1 | 地理総合・歴史総合を置くモデル。公共を置く学校もある | 基礎科目を開始、または科学と人間生活を含む経路を開始 |
| 高2 | 公共を高1・2のいずれかで履修。対応する総合科目の後に探究科目へ進むモデル | 必履修の組合せを満たし、選択する発展科目へ接続するモデル |
| 高3 | 選択した地理探究・日本史探究・世界史探究・倫理・政治経済の深化、横断的な探究 | 選択した物理・化学・生物・地学の深化、観察・実験と総合的な探究 |

高校の「社会」はアプリ上のまとめ名です。正式な教科は「地理歴史」と「公民」です。地理総合・歴史総合・公共は必履修ですが、探究科目や倫理・政治経済を全員がすべて履修するわけではありません。理科も全9科目が全員必修ではありません。学年だけで未履修の内容を自動出題せず、学校の履修科目・学習済み単元を指定できる設計にします。

## 教材化の基本

教科別の学習に加え、[「つながりで学ぶ」](cross-disciplinary-learning.md)を新しい入口として設計しています。科学技術の発展と歴史を横断し、原理・資源・産業・制度・暮らしを関係付けるものです。学年別教材と同じ単元IDを参照し、必要な前提へ寄り道して元のコースへ戻れる構成にします。アプリへの実装・配信は次工程です。

今回の具体的な作問準備は社会・理科を対象にします。英語・国語は範囲調査から既存教材の不足を見つけるために使い、数学は参照資料として残します。

1. 単元表から学習目標を1つ選び、前提知識を確認する。
2. 用語・概念の説明、具体例、図表や資料の読み方をまとめる。
3. 基礎確認・資料解釈・理由説明の3問を試作する。
4. 根拠、唯一の正解、誤答の理由、学年・科目の範囲を別の確認者が点検する。
5. 試作修正後に単元セットへ拡張し、教材原稿とアプリ用データを分けて保存する。

知識の四択問題だけで、観察・実験の技能、探究の過程、表現力、学習に取り組む態度の全てを評価できるわけではありません。アプリで練習できる要素と、学校や実活動で確かめる要素を分けます。

## 完成範囲と引き継ぎ

社会・理科は252の編集単元（中学社会52・中学理科49・高校社会81・高校理科70）に整理しました。英語・国語は概要調査、数学は参照用の概要です。細目を1つずつ採点可能な到達目標へ分割した最終データベース、全範囲の問題集、教科書別対応表、大学入試の出題範囲表は今後の制作対象です。4教材・12問の試作は別のAI担当による解き直しを済ませましたが、原稿段階です。アプリへの取込・公開前に、人による教科専門レビューと試用を行います。

既存の[教材担当の引き継ぎ](https://github.com/takashi-norl/study-app/blob/4bc126c0ec05f76faf5256400fd697f53e0f04b6/docs/CONTENT_HANDOFF.md)に合わせ、資料は `docs/curriculum/` に置きます。アプリへの取込に必要な項目・現行形式との対応は[制作設計](authoring-plan.md)に記載しています。

横断学習では10本のコース案と14本の関係例を用意し、蒸気機関1教材・3問を追加で試作しました。こちらも別のAI担当が解き直し、本文根拠・唯一解・歴史記述を確認済みです。教材原稿は合計5本・15問ですが、全て `draft` であり、人による教科専門レビューと学習者の試用は未実施です。メニューの構想と原稿を4ファイルに分けて追加し、このフォルダは全15ファイルです。

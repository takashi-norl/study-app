# ひび学習

高校生の家族向け学習PWA。英語・国語・社会・理科などの目標をAIと相談し、写真やPDFを繰り返し使って問題を作れます。教材なしの練習にも対応。自作の問題はプライベートライブラリで本人がすぐ使え、保護者は内容と学習履歴を確認できます。Manager・Super Userは問題集単位でパブリックライブラリに公開でき、生徒は公開を依頼できます。

バージョンと更新履歴はアプリの「設定」から確認できます。開発時の更新・公開・タグ付けの手順は [RELEASES.md](RELEASES.md) を参照してください。

## できること

- 設定から会話で学び方プロフィールを作成。目標・興味・使える時間・声かけの好みを本人が確認して保存し、ホームの一言と次の学習相談に反映。手入力・無効化にも対応。
- Super UserとManagerを分離。Claudeの利用記録・概算料金はSuper User専用。画面を開くだけのパーソナライズは追加AI呼び出しなし。

- 教材ストックに写真・PDFを先に保存し、複数の相談や問題集で再利用。
- 問題集名の入力なしで、科目・目的・教材・期間・難しさを選択。「あと1時間」の試験対策、「1か月」の語彙練習、「身につくまで」の習得目標に対応。
- 最初のAI相談で、提案と実際のサンプル3問を作成。コメントで聞き方や難しさを調整し、形式に納得してから総問題数、または日数×1日の問題数を選びます。
- 既存の問題集も「AIと相談してアレンジ」から別のプライベートプランへ。元の問題と学習記録を残して、3問のサンプルから試せます。
- 管理者のテスト作成。問題・相談・テスト回答は生徒の表示と成績から分離し、管理者が試せます。
- プライベートライブラリとパブリックライブラリ。自作の問題は保存済みの分から練習でき、公開は問題集単位。Manager・Super Userが公開し、生徒は公開を依頼します。公開版は原本を残したコピーで、生徒は自分の学習プランに追加できます。
- 英語の設問・選択肢の発音。ElevenLabsまたは端末音声、1倍／0.8倍再生。「使い方」から基本操作の説明動画（以前の画面）と最新の文章ガイドを表示。
- 目標・期限・現在のレベル・1日の目安を保存。AIと会話して学習の進め方や四択問題の案を調整。
- 相談には現在の学習成績の集計を反映。長期計画は相談による提案で、毎日の自動作問・自動的な難易度変更は行いません。
- 生徒自身の相談・作問と、保護者による相談履歴・問題内容の閲覧。
- 写真・PDFから問題集を作成。目標10〜300問、1回20資料まで。資料不足の水増しを避けるため、実際の問題数は目標より少なくなることがあります。
- 原本・根拠・選択肢・正答・解説の任意の確認と編集。問題を1問ずつ承認する操作は練習・ライブラリ公開の必須条件ではありません。
- 毎日の10問、追加10問、苦手問題、問題集の選択。
- 回答日時、最終回答、誤答回数、正答率、次回復習の記録。
- 1・3・7・14・30日の復習間隔。同日中の解き直しや早すぎる復習で習熟度を水増ししません。
- 保護者の学習状況画面。出題率、初回正答率、別日の復習正答率、日別活動、苦手問題。
- Googleログインと家族の許可リスト。ホーム画面への追加、任意の新規公開通知。

## 構成

| 役割 | 保存・実行先 |
| --- | --- |
| iPhone / 保護者画面 | Next.js・ReactのPWA、Vercel |
| 教材の写真・PDF | 保存用GoogleアカウントのDrive、アプリ専用フォルダ |
| 問題・回答・出題履歴 | 同じアカウントのGoogle Sheets、追記専用Eventsタブ |
| ログイン | Google OAuth、サーバー側の家族許可リスト |
| 読み取り・作問 | Claude API、Vercel Workflowで分割実行 |
| 英語音声 | ElevenLabs API（任意）・専用Driveに音声を再利用、端末音声への切替 |
| お知らせ | Web Push。通知の成否と問題公開は独立 |

生徒の端末や保護者のMacを常時起動する必要はありません。Driveの利用権限はサーバーだけが持ち、生徒のログインにはDriveアクセスを要求しません。

Sheetsは少人数の家族用です。全イベントの再読込方式なので、大人数・大量の長期記録には専用DBへの移行が必要です。追記の重複はイベントIDで除き、最初の回答を採用します。出題時の問題を固定保存するため、後日の編集で採点は変わりません。

Node.js 24を使います。

```sh

npm run dev
```

`http://127.0.0.1:3000/?demo=1` は明示的なデモです。サンプル問題・履歴をブラウザに保存し、生徒と保護者を切り替えられます。デモではAI通信・家族間同期・プッシュ通知は実行しません。写真はこのブラウザのIndexedDBにだけ保存されます。

通常の `/` は本番ログイン用です。設定不足時は実データへのアクセスを拒否します。


## 本番セットアップ

1. VercelでこのリポジトリをNext.jsプロジェクトとして登録し、Node.js 24を選択します。
2. [Google接続の手順](docs/GOOGLE_SETUP.md)に沿って、Google OAuthクライアントと教材・記録の保存先を設定します。
3. `.env.example`の値をVercelのEnvironment Variablesに設定します。秘密情報をリポジトリやチャットに貼らないでください。ローカルで接続を試す場合だけ`.env.local`に保存します。
4. Googleのリダイレクト先を `https://本番ドメイン/api/auth/callback/google` に設定します。`NEXTAUTH_URL`と`NEXT_PUBLIC_APP_URL`も同じ本番URLにします。
5. 家族のGoogleメール、表示名、役割を`ALLOWED_FAMILY_MEMBERS_JSON`に設定します。空の設定は誰もログインできません。
6. Claudeのキーと明示的なモデル名、利用予算を決めてから`AI_GENERATION_ENABLED=true`を設定します。初期値は`false`です。
7. 必要ならVAPIDキーを作成して通知を設定します。iPhoneではSafariからホーム画面に追加してから通知を許可します。

VercelのPreviewとProductionで保存先や認証情報を分けてください。プレビューに本番の家族データを接続しないでください。環境変数の変更後は再デプロイが必要です。

## 費用と保存範囲

AIによる読み取り・相談・作問はClaude APIの従量料金がかかります。教材と目標の保存、作成済み問題の採点・復習にはAIを呼びません。作問上限は初期値1日3回・月10回で、1回最大300問。学習相談（提案と試作3問を1回のAI呼び出しで返す）は1日20回・月100回です。試作は通常の作問回数枠を消費せず、サンプルを確かめて分量を決めた最後の操作で本作成を依頼します。プロフィールのAI会話は利用者ごとに1日8回・月40回までで、手入力での編集や保存にはAIを呼びません。これは金額の上限ではありません。Claudeアカウント側にも利用上限を設定し、少量の教材で実費を確認してから増やしてください。障害後に新しい依頼をすると再課金される場合があります。

ElevenLabsは`ELEVENLABS_API_KEY`を本番の秘密設定へ保存すると有効になります。音声ボタンを押した部分だけを生成し、同じ英文・声・モデルの音声はDriveから再利用します。家族全体で新規音声30件/日・300件/月、1件1500文字、計30000文字/日・150000文字/月を上限としています。失敗や結果不明の生成を自動再試行しません。APIの利用料や契約のクレジットはElevenLabs側の条件に従い、この件数制限は金額の保証ではありません。端末音声はこのAPIを呼びません。ガイド動画はMacの内蔵音声で作成しています。

管理者用 `/admin/vocabulary-samples` は、2級50語・準1級50語を10語ずつ学び、意味・英単語・英文の空欄・使い方の4種類の選択式から選び、各セット10問ずつ確認する100語セットです。形式ごとに回答と結果を分け、空欄問題に正解するとその文で使える登録済みの別表現を表示します。採点・類義語の表示にAIを呼びません。各語に発音と3例文を収録します。テストの回答はタブ内だけに保持し、学習者には未公開です。例文の単語・熟語は基礎46項目を含む用語説明へつながり、本人の参照履歴と復習候補・確認済み状態はDriveのイベント記録に保存します。動詞は原形・過去形・過去分詞・ing形・三単現を表示し、活用形も同じ用語の履歴にまとめます。活用表は確認済みの有限の辞書データで、未収録語の活用を推測しません。

100語の初回音声準備だけは、Super User専用の固定カタログ処理で通常の30件/日枠を分けています。100件・合計35000文字以内のカタログのみ受け付け、家族全体300件/月・150000文字/月の上限は引き続き適用します。保存済みの旧6語は再生成せず、新しい94語を順番に保存します。画面を閉じても継続し、失敗・結果不明の予約を自動再生成しません。通常の任意音声生成の上限は変更していません。

Vercel・Googleの既存プラン、使用量、保存容量、最新の各サービスの条件も適用されます。アプリはプラン変更や支払い登録を自動で行いません。

写真は端末上で長辺2400px以内のJPEGに調整し、位置情報などのEXIFを含めず送信します。アップロードするコピーは元写真と異なります。画像の判読性はレビューで確認してください。PDFは1件10MBまで。HEICはブラウザが読み込める場合に変換し、非対応ならJPEGでの保存を案内します。

Claudeへ送るのは選んだ教材、目標・レベル、会話、作問に必要な問題内容と学習成績の集計です。家族のメールや生の回答履歴は送信しません。自作の問題は生徒・管理者ともに承認なしで練習できます。AIが作る内容には誤りがあり得るため、解説や資料も参照できます。

## 安全性と運用

- `takashi.oikawa@gmail.com`だけをSuper Userとして、確認済みGoogleセッションと現在の許可リストから毎回判定します。その他の保護者はManagerです。ブラウザから権限を変更する機能はありません。
- 料金は専用認証APIからのみ取得し、通常の学習データ・Managerの書き出しには含めません。利用記録の開始前の金額は復元せず、失敗・不明モデル・未完了の課金額は未確定と表示します。ElevenLabsは利用件数・文字数のみで、契約プランが不明な金額を推測しません。
- 学び方プロフィール・作成会話は本人用APIに分離し、他の家族のプロフィールは取得できません。性格の診断や敏感な属性の推測は行わず、本人が確認した学習上の好みだけを利用します。保存先Googleアカウントの所有者は記録を管理できます。

- 練習用の未回答問題では正答・解説・出題時の解答付きスナップショットを生徒に送信せず、採点はサーバー側で行います。作問相談のサンプル3問は、形式を確認するため正答・解説も表示します。本人が保存した原本は教材ストックで閲覧できます。
- 設定済みの家族・役割・Googleの確認済みメールを毎回検証します。
- Googleのアクセストークン、リフレッシュトークン、Claudeキーはブラウザに渡しません。
- 原本は認証付きAPIで取得し、保護者は全教材、生徒は自分の教材だけを閲覧できます。Driveの「リンクを知っている全員」共有は不要です。
- アップロード先は特定ファイル専用の一時URLです。このURLも第三者へ共有しないでください。
- 学習データをService Workerにキャッシュしません。オフラインでは接続の案内を表示します。
- 元のEventsタブは並べ替え・手動編集せず、バックアップ用コピーを取ってください。学習記録は管理者のGoogle Driveでもアクセス管理が必要です。
- 保護者の「書き出す」はJSONのデータ出力です。写真・PDF本体は含みません。

実Googleアカウントでのアップロード・共有、実Claudeによる教材精度、実機iPhoneの通知は、接続設定後に確認が必要です。ローカルのテストとデモ画面の検証は、この実接続確認の代わりにはなりません。

## AI処理を待つ画面の設計

受付済みであること、実際の処理段階、離れた後の戻り先を示します。教材の確認件数は保存済みの読み取り結果から数え、時間だけで進む割合や架空の残り時間は表示しません。今回の依頼で成功した読み取りが3件以上ある場合だけ、その実測範囲から残りの読み取り時間を見積もります。この目安には、提案を考える時間や保存時間を含めません。教材の分量によっても変わるため、完了時刻の約束にはしません。

待機中はほかの画面へ移動できます。このブラウザで進行中に確認した本人の依頼をアカウント別に追跡し、完了・失敗のお知らせから元の学習プランへ戻します。端末に保存する追跡情報は依頼IDだけです。最新の状況を取得できないことと、処理自体の失敗は区別します。状況確認は結果と実行状態の確認に限定し、有料AIへの再依頼にはしません。

参考にした研究・指針は次のとおりです。ここでの採用は本アプリへの設計上の推論であり、継続率や離脱率の改善を測定した結果ではありません。

- [Tan & Nov, Counting the Wait（2026・著者公開原稿）](https://arxiv.org/html/2602.04138v1)：425人を対象とした固定の10〜60秒待機では、残り時間表示が経過時間表示より不満を強めた条件がありました。正確なカウントダウンが常に最善とはいえません。米国成人のPC上での実験なので、数分の不確実なAI処理や日本の高校生への効果は別途確認が必要です。
- [Hui, Thakor & Gill（1998・著者所属大学の公開要旨）](https://research.cuhk.edu.hk/en/publications/the-effect-of-delay-type-and-service-stage-on-consumers-reactions-2/)：待つ段階の影響は、その遅延が処理の完了を脅かす性質かどうかでも変わりました。「待つ場所だけでストレスが決まる」という一般則ではなく、受付と完了への見通しを伝える際の参考にしています。確認範囲は要旨です。
- [NN/G, Designing for Long Waits and Interruptions（2021）](https://www.nngroup.com/articles/designing-for-waits-and-interruptions/)：正確な時間を示せない場合の実際の処理段階、長い処理から離れられること、戻った際の結果と再開先を示す指針を参考にしています。特定の表示による離脱抑制を証明した比較実験ではありません。

## 教材検索の現状と次の拡張

現在は写真・PDFの原本をDriveに残し、本文・学習項目・判読が不確かな箇所の読み取り結果をSheetsの`source.analysis`イベントに保存しています。同じ教材を再び選ぶと保存済みの結果を再利用し、原本を毎回AIで読み直しません。相談には利用者が選んだ教材の読み取り結果を文字数の範囲内で渡します。全教材を横断するベクトル検索や検索用DBへの移行は、まだ行っていません。

教材が増えた段階では、まず教材ID・版・ページや節・科目・単元・学習目標などのメタデータと、参照元に戻れる本文の区切りを整えます。その上で、語句の一致を使う検索と意味の近さを使う検索を組み合わせ、目的に合う箇所だけを相談や作問に渡す構成を検討します。検索前に利用者の閲覧権限とテスト教材の区分を適用し、回答から元の資料を確認できる対応関係を保ちます。これは次の実装候補であり、Drive原本や現在の学習記録の移行、検索サービスの契約・追加料金の発生を伴う変更は今回実施していません。


## 作問の分割と復旧（v0.4.3）

作問は1バッチ最大10問とし、結果をバッチごとに保存します。作問APIの応答期限は180秒、それ以外は90秒です。自動の有料再試行は行いません。応答が不明な同一バッチには再送ガードを設けています。障害種別とHTTPステータスなど、秘密情報・本文を含まない診断だけをサーバーログに残します。

利用者が「同じ条件で続きを作る」を押すと、保存済みの条件・同じ問題集を使った新しい作問依頼を作ります。既存の問題を目標数に含め、残りだけを生成します。同じ失敗依頼からの重複操作は同じ再依頼に解決し、別端末からの操作でも増殖させません。本人の権限、教材へのアクセス、共通の実行枠、通常の作問回数上限を確認します。失敗したAI呼び出しにも料金が発生する場合があり、再依頼も利用回数に含みます。

## プライベートとパブリック（v0.5.0）

プライベートライブラリは本人の学習用です。生徒同士には共有せず、管理者は従来どおり内容と学習履歴を確認できます。以前の版で作られた未承認の問題も、本人の自習で使えます。管理者のテスト用セットとテスト回答は生徒から見えません。

パブリックライブラリの閲覧範囲は、この家族アプリにログインできる登録ユーザーです。インターネット全体への匿名公開ではありません。一般ユーザーは自分の問題集について公開を依頼し、Manager・Super Userが問題集単位で公開します。個々の問題への正答確認チェックは必須ではなく、公開は正確性の保証を意味しません。

公開版には問題・選択肢・正答・解説をコピーします。元の写真・PDFへの参照、教材ID、相談履歴、元の私的な学習プランは添付せず、原本はプライベートに残します。作問中のセットは完成後に公開でき、公開済みの版は直接変更せず原本の編集から新しい版を作ります。


## 3問で相談してから本作成（v0.6.0）

新しい相談は、実物の四択サンプル3問を含む案を1件返します。教材不足で信頼できる問題を作れない場合は、推測で3問を埋めずに不足と次の操作を回答します。試作は相談履歴にだけ保存し、問題集の件数、練習、公開には入りません。調整コメントでは直近の実サンプルと作問指示を引き継ぎます。画面を開く・試作のページを送る・分量を選ぶだけでは追加のAIを呼びません。

本作成は、本人の現在のプラン版・相談・提案に含まれる3問と明示的な承認をサーバーで照合します。新しい相談の後は古い試作で作れません。総数か日数×1日の量を1〜300問の範囲で検証し、承認した実サンプルと作問指示を作成依頼に固定保存して各10問の生成に渡します。試作3問はこの総数に含めず、見本と同じ設問を再保存しないよう検査します。既存の失敗した作問の再開は保存済み条件を引き継ぎますが、旧画面からサンプルなしで新たに大量作問する経路は無効です。

アレンジの入口では、新しい本人用プランに元問題の代表例を最大3問保存します。この保存だけではAIを呼ばず、本人が希望を送信したときに試作を作ります。元の問題集と学習記録は変更しません。公開版からのアレンジには元の非公開教材を添付せず、本人が読める資料だけを扱います。

試作を含む相談のAPI応答期限は180秒です。以前の提案だけの処理と分けて実測時間を集計し、自動の有料再試行は行いません。件数制限は料金の上限を保証するものではありません。

## 一覧レビュー・ユーザー表示・学習プランのまとまり（v0.7.0）

管理者ホームの「写真から作る → 一覧でレビュー → 問題集を公開 → ユーザー表示を確認」から進められます。一覧レビューでは問題文・選択肢・正解・学習ポイントを並べ、教材／ポイント／科目の内訳、検索、要確認だけの絞り込みで全体の傾向を確認できます。編集後は一覧の位置に戻り、前後の問題へ進めます。個別の確認状態と、問題集の公開範囲を分けて表示します。

「ユーザーとして見る」は管理者専用です。同じ家族の登録済み学習者を選び、実際の学習者表示と出題権限で絞った問題を確認します。非公開の管理者用・テスト用問題、他人の非公開問題、未追加の公開問題は練習に混ざりません。公開カタログで見えることと、学習に追加して出題されることを区別します。試し解きはブラウザの一時メモリだけで行い、実際の回答・出題履歴・学習プラン・復習予定を保存しません。プレビューの英語音声は端末の読み上げのみです。

学習者は「学習プラン」から、計画に「中間テスト」「英語」など最大8個のタグを付けられます。同じタグを持つ計画をプロジェクトのようにまとめ、回答済みの問題数／全問題数、初回正答率、復習対象を確認できます。同じ問題を繰り返しても進度の分子は増えず、複数プランにある同一問題はまとめの中で重複計上しません。回答済み率は取り組んだ範囲で、習得率ではありません。作成前の計画は問題0問として表示します。

タグは本人のみが保存でき、管理者のユーザー表示モードでは変更しません。整理用のタグ変更はAI相談の承認版を更新せず、実行中の作問が完了しても保持します。既存の学習記録や公開範囲は変更しません。

# 高校理科：高1〜高3の教材・問題制作に向けた範囲表

確認日：2026-10-24。対象は、高等学校学習指導要領（平成30年告示）の共通教科「理科」全9科目。2022年度入学生から適用される課程を基準とする。本文の項目名・項目番号と、このアプリの編集上の単元分割・到達目標・教材案を区別した作業用資料である。

**高校理科の範囲は、全国一律の高1・高2・高3別には決まっていない。科目を主軸として管理し、学校の教育課程に合わせて学年を対応付ける。全9科目を全員の必修範囲として扱わない。**

共通の必履修条件は次のいずれか。これは最低限の組合せであり、学校はこれを超えて科目を設けられる。

- **組合せA**：科学と人間生活 ＋ 物理基礎・化学基礎・生物基礎・地学基礎から1科目。標準単位数で計4単位。
- **組合せB**：物理基礎・化学基礎・生物基礎・地学基礎から3科目。標準単位数で計6単位。

物理・化学・生物・地学を1科目履修しただけで、上の基礎科目の組合せを自動的に満たすとは扱わない。標準単位数は国の基準で、学校が定める実際の単位数・開設年次とは分けて保存する。1単位は35単位時間を標準とし、通常の授業の1単位時間は50分を標準とするが、アプリの1レッスン数への機械的換算には使わない。

根拠：S1 第1章第2款3(1)・(2)、第2章第5節第3款1(2)；S2 第1章第4節 pp.23–25、第3章1(2) pp.182–183。S2 は各科目の履修年次を指定していないことを明記している。

## 13. 探究・実験と評価を教材へ落とす

S1 の各科目「3 内容の取扱い」および第3款、S2 第3章 pp.181–188 を根拠に、観察・実験を単元末のおまけにしない。基礎科目では内容に適した探究の方法を積み上げ、物理・化学・生物・地学では科目全体を通じ探究の全過程を経験できる構成を目指す。全過程を毎問要求するという意味ではない。

| 制作する要素 | 学習者の行為 | 問題・教材に持たせる情報 | 評価の着眼点 |
|---|---|---|---|
| 問いと仮説 | 観察から検証可能な問いを作る | 元の観察、既知条件、候補仮説 | 問いと仮説の対応、検証可能性 |
| 計画と条件制御 | 変える条件・そろえる条件を決める | 器具の選択肢、対照、測定回数 | 仮説を区別できる計画か |
| 測定・記録 | 数値・単位・観察事項を記録する | 器具の目盛り、分解能、測定条件 | 記録の一貫性、安全な操作 |
| 分析・解釈 | 表・グラフ・式・モデルを用いる | 生データ、誤差、外れ値の状況 | データから言えることと限界の区別 |
| 結論と表現 | 根拠を示し、仮説を再検討する | レポート枠、反証・別解の資料 | 主張と証拠の対応、改善案 |

実験を画面上で正答できても実技を習得したとはみなさない。実物操作が必要な技能は `requires_observation` 等で区別する。薬品・加熱・電気・微生物・野外観察を扱う教材は、教師の指導、器具管理、廃棄、現地の安全条件を制作時に点検し、危険な自己実験を誘導しない。採点可能な知識・技能、思考・判断・表現と、継続的な学習の過程を分けて記録する。

## 14. 誤概念を見分ける問題の候補

この表は本アプリの編集案。誤答の理由を同じ選択肢で混同しないため、正誤判定の後に根拠選択・短い説明を組み合わせる。

| 領域 | 誤概念の候補 | 確認するための場面 |
|---|---|---|
| 力・運動 | 動いている物体には進行方向の合力が必要 | 等速運動と加速運動を比較し、合力を描く |
| 力・運動 | 作用・反作用の2力は同一物体上でつり合う | それぞれの力を受ける物体を明示する |
| 波・熱 | 波と一緒に媒質が運ばれる／温度と熱量は同じ | 波形動画と粒子追跡、量の異なる水の熱量比較 |
| 電気 | 電流が負荷で消費される／電位と電界は同じ | 回路の測定点、等電位線と電界の向きを問う |
| 化学基礎 | 強酸は必ず濃い／同体積なら同じ物質量 | 強弱・濃度・体積を独立に変えた条件比較 |
| 化学 | 化学平衡では反応が停止する／触媒は平衡組成を変える | 正逆反応速度のグラフと最終濃度を比較する |
| 生物 | 進化は個体が必要に応じて変化すること | 変異が既にある集団の世代変化を扱う |
| 生物 | 分化した細胞は不要な遺伝子をすべて失う | ゲノムと発現量を分けた資料を与える |
| 生態系 | エネルギーも物質と同じように循環する | 物質循環図とエネルギー流の図を描き分ける |
| 地学 | 地震を起こすプレートは地殻だけ／季節は太陽までの距離だけで決まる | 内部構造図、両半球の季節・太陽高度を比較する |

## 15. 次の制作作業と範囲管理

1. **学校ごとの科目選択・学年設定を作る。** 未履修の科目や「科学と人間生活」の未選択項目を自動出題しない。
2. **1行を複数の小目標に分ける。** 本表は範囲台帳で、1行＝1問・1授業ではない。例えば PHYB-02 は力の識別、つり合い、運動法則、落下へ分割する。
3. **各小目標に、導入→図解→確認→データ解釈→説明問題を用意する。** 表の教材例から着手し、必ず独自の数値・図・文章で作る。
4. **告示の扱いの深さを記録する。** 「扱う」「触れる」等の区別を原資料で再確認し、補充・発展・大学入試固有の技巧を必修範囲に混ぜない。本表の具体語のすべてを同じ深さで要求しない。
5. **科目全体の漏れを確認する。** 科学と人間生活3、物理基礎2、物理4、化学基礎3、化学5、生物基礎3、生物5、地学基礎2、地学4の大項目を、選択条件込みで点検する。
6. **問題公開前に専門レビューする。** 解答の一意性、単位・桁・符号・図の縮尺、実験条件、科学的妥当性、出典に照らした範囲、教材に使用する図表の権利を確認する。

入試過去問への対応、採用教科書のページ対応、学校別配当、実験手順の詳細、全小項目の個別採点ルーブリックは未作成。これらを本表に付加すれば、履修範囲と問題生成・教材生成を接続できる。

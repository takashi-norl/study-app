# ひび学習

自分の教材で、自分のペースで学ぶ学習PWA。写真・PDFからAIと相談して問題を作り、1回10問の練習と復習を進めます。現在は招待制のテスト利用で、月額料金は未定、課金は開始していません。

写真・PDF、作った問題、学習プラン、AIとの会話、成績は本人専用です。共有・公開・配布、他の利用者としてのプレビューは停止しました。既に本人の問題集として保存されている問題は、そのまま学べます。アプリの運営はWebの `/admin` に分け、招待・利用停止、届いた感想、AIの利用管理を行います。

バージョンの正本は `src/lib/releases.ts` です。公開手順は [RELEASES.md](RELEASES.md) を参照してください。

## 学習の流れ

1. 招待リンクを開き、招待先のメールアドレスを確認できる自分のアカウントで参加します。既定はGoogleで、Appleは設定・確認を完了した環境だけで利用できます。登録後も最初に登録した方法を使い、ログインは30日間保持します。
2. 用意された共通教材から学ぶか、自分の写真・PDFを教材ストックに追加します。共通教材に個人のアップロード教材は含まれません。
3. 科目・目的・期間・難しさを選んでAIと相談し、まず実際の3問を確認します。古文の「単語問題」は `skills/kobun-vocabulary/SKILL.md` と共通テンプレートに沿って作成します。
4. 聞き方や難しさを調整してから分量を選んで作成します。一覧レビューでは問題・選択肢・正解・学習ポイント・原本を確認し、本人が編集できます。
5. 「中間テスト」「古文」などのタグで学習プランをまとめ、自分の進み具合を確認します。進度は取り組んだ範囲であり、習得率ではありません。
6. 答えをタップするとすぐに結果と解説が出ます。開始前に「答え合わせボタンを使う」へ切り替えることもできます。回答時の動き・振動は任意で、効果音は鳴りません。
7. 気づいたことを設定の「感想・不具合を送る」から運営へ送れます。教材・会話・成績は自動添付しません。

間違えた問題や復習対象を選べます。復習間隔は1・3・7・14・30日で、同日中の解き直しや早すぎる復習で習熟度を水増ししません。学び方プロフィールは本人が確認・保存した好みだけを使います。学習計画は提案であり、自動作問の予約ではありません。

## 運営画面と招待

`/admin` のAdmin Consoleは確認済みの運営アカウント（Super User）だけが使えます。運営者も通常のアプリでは一人の学習者として、自分の教材と学習記録を使います。運営権限は別の能力として管理し、他の利用者の学習成績や教材を閲覧する権限は与えません。招待画面ではログインに使うメールアドレスを指定して期限付きリンクを作り、運営者が本人へ渡します。アプリは招待メールを自動送信しません。

- 招待は1・7・14日の有効期限から選択し、指定先とログイン提供元が確認したメールの一致を確認して、その提供元の本人IDに結び付けます。
- 使用前の招待取消、登録済みテスト利用者の利用停止に対応します。停止はデータ削除ではありません。
- 同時に有効な招待は50件、追加登録は50人までです。一般公開の自由登録ではありません。
- Google OAuth側の公開状態・テストユーザー設定によっては、招待済みでもGoogleがログインを制限します。実際の新規参加アカウントで確認が必要です。
- 固定教材の有料音声準備や確認済み問題の取り込みも運営権限に限定します。問題の取り込み先は運営者本人の問題集です。

Appleログインは任意で、既定は無効です。GoogleとAppleのメールが一致してもアカウントを自動連携せず、連携用の操作もまだ提供していません。既存利用者は最初に登録した方法でログインします。Appleの「メールを非公開」を使う場合は、そのリレーアドレス宛ての招待が必要です。[Appleの設定・本人確認・有効化前の確認](docs/APPLE_SETUP.md)を参照してください。

料金は未定です。支払い依頼の実装・決済サービスの接続・月額請求は行っていません。将来支払いを依頼する場合も、支払う人に教材や学習記録を見せる仕組みにはしません。

## 構成

| 用途 | 保存・実行先 |
| --- | --- |
| 学習PWA・運営Web | Next.js・React、Vercel |
| 写真・PDF | 運営が管理するGoogle Driveの専用フォルダ |
| 問題・回答・出題 | 運営アカウントのGoogle Sheets、追記専用Eventsタブ |
| 招待・感想 | 同じシートの専用Operationsタブ。学習記録とは別に保存 |
| ログイン | Google OAuth＋任意のApple（既定無効）、既存登録＋メール指定の招待 |
| 読み取り・相談・作問 | Claude API、Vercel Workflow |
| 英語の発音 | ElevenLabs API（任意）、保存済み音声・端末音声 |

利用者のログインにDrive権限は要求しません。保存用のGoogle接続はサーバー専用です。学習データはアプリのAPIで本人だけに絞りますが、保存先Drive・Sheetsの所有者は障害対応や削除対応のために記録を管理できます。端末のみへの保存や、運営者にも読めない暗号化を提供する構成ではありません。

招待と感想は `${GOOGLE_SHEETS_EVENTS_TAB}_Operations` タブへ保存します。初回の書き込み時だけタブを作り、未存在の読み取りでは作りません。既存のEventsタブへ新しい種類を書き込まないため、Eventsだけを読む旧版の進行中処理は引き続き学習記録を読めます。新しい認証・利用停止はこのOperationsタブも参照するため、バックアップとアクセス管理の対象に含めてください。

最初のApple登録後は、Operations内のApple会員形式を読めない版へ戻すと、Google利用者を含む全体の状態読み込みが失敗します。Appleを無効に戻すだけでは解消しません。有効化前にApple対応の読み取り処理を含む版を最低復旧先として保存してください。[復旧先の制約](docs/APPLE_SETUP.md#復旧先の制約)に従い、対応前の版へそのまま戻したり、会員記録を削除したりしないでください。

Sheetsの全イベントを読み込む方式は少人数のテスト向けです。大人数・大量の長期記録には専用DBへの移行が必要です。イベントIDで重複を除き、最初の回答を採用します。出題時の問題を固定保存し、後の問題編集で採点が変わらないようにしています。今後のDB・ファイル保存・ユーザー管理は [多人数利用に向けた設計](docs/MULTI_USER_ARCHITECTURE.md) を参照してください。この設計への移行はまだ実装していません。

## ローカルで確認

Node.js 24を使います。

```sh
npm ci
npm run dev
```

`http://127.0.0.1:3000/?demo=1` は明示的なサンプルモードです。本人だけの操作を試し、問題・履歴をブラウザに保存します。AI通信、実データの同期、運営機能は実行しません。サンプルの写真はブラウザのIndexedDBにだけ保存されます。ローカルではクラウド接続を許可せずTEST表示にします。ログイン・保存の結合テストは専用Stagingで行います。

```sh
npm test
npm run test:server
npm run typecheck
npm run build
```

ローカルのテスト・デモ検証だけでは、新規アカウントの参加、Appleの実ログイン、AIの教材精度、実機の振動・PWA動作までは確認できません。

## 本番セットアップ

1. VercelでNext.jsプロジェクトを登録し、Node.js 24を選びます。
2. [Google接続の手順](docs/GOOGLE_SETUP.md)に沿って、Google OAuthと運営用保存先を設定します。
3. `.env.example` を参照し、対象環境の値をVercelへ登録します。そのままコピーせず、[環境の照合契約](docs/STAGING_PLAN.md)に従ってproject IDと `APP_ENV_BINDINGS_JSON` を設定します。既存本番の互換経路はこの文書の条件に限定されます。秘密情報をリポジトリやチャットに貼らないでください。
4. Googleのリダイレクト先を `https://本番ドメイン/api/auth/callback/google` に設定し、`NEXTAUTH_URL` と `NEXT_PUBLIC_APP_URL` も同じ本番URLにします。
5. `WORKSPACE_ID` に保存先の識別子を設定し、既存利用者と運営アカウントを `REGISTERED_ACCOUNTS_JSON` に `id`・`email`・`name` の形式で登録します。全員が本人の学習アカウントで、運営権限は確認済みGoogleメールとサーバー側の登録から別途判定します。空・不正・重複した登録はログインを拒否します。新しいテスト利用者は招待イベントで管理し、環境変数の変更は不要です。
6. Claudeのキー・モデル・利用予算を決めた後に `AI_GENERATION_ENABLED=true` を設定します。初期値は `false` です。

Stagingは別のVercel project、Google OAuth client、保存先、署名鍵を使います。初期は外部処理の4フラグをfalseにした画面確認環境です。本番projectのPreviewや未知のprojectからクラウドへ接続することはできません。環境変数変更後は再デプロイが必要です。旧デプロイで開始済みのWorkflowを止める操作は別途必要です。

既存環境のアカウントID・保存先IDは変更しないでください。旧設定の読み取りは `src/server/legacy-settings.ts` に隔離して引き継ぎます。新しい設定名を使う場合も同じIDを指定し、Sheetsの4列目の位置・値や既存イベントを書き換えません。

## 費用・AI処理・復旧

AIによる読み取り・相談・作問は従量料金が発生します。作成済みの問題の採点・復習にはAIを呼びません。現在の既定上限は全体の作問3回/日・10回/月、相談20回/日・100回/月です。プロフィール会話は本人ごとに8回/日・40回/月。招待登録でこれらの上限を増やすことはありません。件数上限は金額上限ではないため、AI提供元の利用上限も設定してください。

作問は1バッチ最大10問、目標1〜300問で、保存済みの問題から学べます。資料が不足する場合は水増しせず、目標より少なくなることがあります。最初の3問は試作で、本人がその案を確認して本作成を依頼します。新しい相談後に古い試作から本作成することはできません。

処理待ち画面は実際の処理段階を表示し、時間だけで進む架空の進度は使いません。別画面へ移っても本人の依頼の完了・失敗から元の学習プランへ戻れます。状況確認だけで有料処理を再送しません。失敗後の「同じ条件で続きを作る」は、既存問題を残して不足分だけを新たに依頼します。再依頼は利用回数に含み、失敗した呼び出しにも費用が発生する場合があります。

ElevenLabsを設定した場合、必要な英文の音声を生成し、同じ内容をDriveから再利用します。通常の新規音声は全体30件/日・300件/月、1件1500文字、計30000文字/日・150000文字/月。運営の固定教材準備には別の日次枠がありますが、月次上限を維持します。失敗・結果不明の生成を自動再試行しません。英語発音の明示的な再生と、回答時の効果音は別機能です。

## 本人専用のデータと保存範囲

- 写真は長辺2400px以内のJPEGへ調整してEXIFを含めず送信。PDFは1件10MB、1回20資料まで。HEIC非対応ブラウザではJPEGへの変更を案内します。
- Claudeへ送るのは選択した教材、目標・レベル・相談、必要な問題内容と学習成績の集計です。メールアドレスや生の回答履歴は送りません。
- 教材の読み取り結果を保存して再利用します。全教材横断のベクトル検索は未実装です。
- 学習用の未回答問題は正解・解説を隠し、採点はサーバーで行います。本人の一覧レビュー・編集や試作では正解を確認できます。
- 写真・問題・学習プラン・会話・回答・出題・練習セッションは、所有者・本人IDで絞ります。他人のIDを送っても取得・更新できません。
- 旧共有・公開・配布・ユーザープレビューのAPIは410で拒否します。旧パブリック問題は通常の学習へ表示しません。既に本人所有として保存済みの問題は維持します。
- 感想は入力した文章・分類・内部アカウントID・日時・版だけを記録します。1人1日5件まで、同じ送信の再試行は重複登録しません。
- 認証・AI・Google保存用の秘密情報はブラウザへ渡しません。教材APIには認証を要求し、Driveのリンク共有は不要です。
- 学習データをService Workerにキャッシュしません。オフラインでは接続の案内を表示します。
- 元のEventsタブを並べ替え・手動編集しないでください。運営用Googleアカウントのアクセス管理とバックアップも必要です。

教材の権利・利用条件を守って利用してください。個人利用に限定することだけで、すべての教材の保存・AI処理が許諾されるわけではありません。

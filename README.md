# ひび学習

自分の教材で、自分のペースで学ぶ学習PWA。写真・PDFからAIと相談して問題を作り、1回10問の練習と復習を進めます。現在は招待制のテスト利用で、将来の月額料金は暫定1,000円、課金は開始していません。

写真・PDF、作った問題、学習プラン、AIとの会話、成績は本人専用です。共有・公開・配布、他の利用者としてのプレビューは停止しました。既に本人の問題集として保存されている問題は、そのまま学べます。アプリの運営はWebの `/admin` に分け、招待・利用停止、届いた感想、AIの利用管理を行います。

バージョンの正本は `src/lib/releases.ts` です。公開手順は [RELEASES.md](RELEASES.md) を参照してください。

## 学習の流れ

1. 招待リンクを開き、指定された自分のGoogleアカウントで参加します。登録後は通常のGoogleログインを使い、ログインは30日間保持します。
2. 用意された共通教材から学ぶか、自分の写真・PDFを教材ストックに追加します。共通教材に個人のアップロード教材は含まれません。
3. 科目・目的・期間・難しさを選んでAIと相談し、まず実際の3問を確認します。古文の「単語問題」は `skills/kobun-vocabulary/SKILL.md` と共通テンプレートに沿って作成します。
4. 聞き方や難しさを調整してから分量を選んで作成します。一覧レビューでは問題・選択肢・正解・学習ポイント・原本を確認し、本人が編集できます。
5. 「中間テスト」「古文」などのタグで学習プランをまとめ、自分の進み具合を確認します。進度は取り組んだ範囲であり、習得率ではありません。
6. 答えをタップするとすぐに結果と解説が出ます。開始前に「答え合わせボタンを使う」へ切り替えることもできます。回答時の動き・振動は任意で、効果音は鳴りません。
7. 気づいたことを設定の「感想・不具合を送る」から運営へ送れます。教材・会話・成績は自動添付しません。

間違えた問題や復習対象を選べます。復習間隔は1・3・7・14・30日で、同日中の解き直しや早すぎる復習で習熟度を水増ししません。学び方プロフィールは本人が確認・保存した好みだけを使います。学習計画は提案であり、自動作問の予約ではありません。

## 運営画面と招待

`/admin` は確認済みの運営アカウント（Super User）だけが使えます。利用者の学習成績や教材を監視する画面はありません。招待画面ではGoogleメールを指定して期限付きリンクを作り、運営者が本人へ渡します。アプリは招待メールを自動送信しません。

- 招待は1・7・14日の有効期限から選択し、指定された確認済みGoogleメールとアカウントIDに結び付けます。
- 使用前の招待取消、登録済みテスト利用者の利用停止に対応します。停止はデータ削除ではありません。
- 同時に有効な招待は50件、追加登録は50人までです。一般公開の自由登録ではありません。
- Google OAuth側の公開状態・テストユーザー設定によっては、招待済みでもGoogleがログインを制限します。実際の新規参加アカウントで確認が必要です。
- 固定教材の有料音声準備や確認済み問題の取り込みも運営権限に限定します。問題の取り込み先は運営者本人の問題集です。

将来の料金方針は以下の暫定案です。現在は無料テスト利用を続け、支払い依頼の実装・決済サービスの接続・月額請求は行っていません。将来支払いを依頼する場合も、支払う人に教材や学習記録を見せる仕組みにはしません。

2026年10月24日の暫定方針：

- 月額サブスクリプションは1人1,000円。1,000人の有料利用で月額売上100万円を想定します。
- 追加AI利用は、AI原価に30％を上乗せする案です（原価100円なら請求130円）。月額に含むAI利用量、追加分の原価集計・請求方法、税込／税抜の扱いは未確定です。
- 初期開発・導入費を除いた、月々の売上に対する利益率50％を目標にします。AI・決済手数料・保存／通信・運用費などの継続費用を含めます。追加AIの売上・費用がない基準ケースでは、売上100万円に対して月々の総費用50万円以内・利益50万円が目安です。

追加AI単体の売上に対する利益率は約23.1％です。全体で50％を目指す際は、この追加分も合算して判断します。月の追加AI原価をC円、それ以外の継続費用（追加分の決済手数料を含む）をF円とすると、有料1,000人のケースでは売上が `1,000,000 + 1.3C`、費用が `F + C`、利益率50％以上の条件は `F ≤ 500,000 − 0.35C` です。Cが10万円ならFは46.5万円以内が目安です。料金・費用は同じ税の扱いで比較し、未確定の請求仕様をこの試算だけで確定しません。

AI費用を5分の1にすることは必須条件とせず、まず問題の品質とアプリの使いやすさを整え、招待した利用者のフィードバックを優先します。実際の利用量と継続費用を見て、課金開始前に月額に含める範囲と追加利用の条件を決めます。

## 構成

| 役割 | 保存・実行先 |
| --- | --- |
| 学習PWA・運営Web | Next.js・React、Vercel |
| 写真・PDF | 運営が管理するGoogle Driveの専用フォルダ |
| 問題・回答・出題 | 運営アカウントのGoogle Sheets、追記専用Eventsタブ |
| 招待・感想 | 同じシートの専用Operationsタブ。学習記録とは別に保存 |
| ログイン | Google OAuth、既存登録＋メール指定の招待 |
| 読み取り・相談・作問 | Claude API、Vercel Workflow |
| 英語の発音 | ElevenLabs API（任意）、保存済み音声・端末音声 |

利用者のログインにDrive権限は要求しません。保存用のGoogle接続はサーバー専用です。学習データはアプリのAPIで本人だけに絞りますが、保存先Drive・Sheetsの所有者は障害対応や削除対応のために記録を管理できます。端末のみへの保存や、運営者にも読めない暗号化を提供する構成ではありません。

招待と感想は `${GOOGLE_SHEETS_EVENTS_TAB}_Operations` タブへ保存します。初回の書き込み時だけタブを作り、未存在の読み取りでは作りません。既存のEventsタブへ新しい種類を書き込まないため、旧版の進行中処理も既存の学習記録を読めます。新しい認証・利用停止はこのOperationsタブも参照するため、バックアップとアクセス管理の対象に含めてください。

Sheetsの全イベントを読み込む方式は少人数のテスト向けです。大人数・大量の長期記録には専用DBへの移行が必要です。イベントIDで重複を除き、最初の回答を採用します。出題時の問題を固定保存し、後の問題編集で採点が変わらないようにしています。

## ローカルで確認

Node.js 24を使います。

```sh
npm ci
npm run dev
```

`http://127.0.0.1:3000/?demo=1` は明示的なサンプルモードです。本人だけの操作を試し、問題・履歴をブラウザに保存します。AI通信、実データの同期、運営機能は実行しません。サンプルの写真はブラウザのIndexedDBにだけ保存されます。通常の `/` は本番ログイン用で、設定不足時は実データへのアクセスを拒否します。

```sh
npm test
npm run test:server
npm run typecheck
npm run build
```

ローカルのテスト・デモ検証だけでは、新規Googleアカウントの参加、AIの教材精度、実機の振動・PWA動作までは確認できません。

## 本番セットアップ

1. VercelでNext.jsプロジェクトを登録し、Node.js 24を選びます。
2. [Google接続の手順](docs/GOOGLE_SETUP.md)に沿って、Google OAuthと運営用保存先を設定します。
3. `.env.example` の値をVercelの秘密設定へ登録します。秘密情報をリポジトリやチャットに貼らないでください。
4. Googleのリダイレクト先を `https://本番ドメイン/api/auth/callback/google` に設定し、`NEXTAUTH_URL` と `NEXT_PUBLIC_APP_URL` も同じ本番URLにします。
5. 既存利用者と運営アカウントを `ALLOWED_FAMILY_MEMBERS_JSON` に設定します。この環境変数名・内部の `parent` / `student` は既存データとの互換用です。運営権限は確認済みメールに基づくSuper User判定で、旧 `parent` だけでは付与しません。空・不正な設定はログインを拒否します。新しいテスト利用者は招待イベントで管理し、環境変数の変更は不要です。
6. Claudeのキー・モデル・利用予算を決めた後に `AI_GENERATION_ENABLED=true` を設定します。初期値は `false` です。

PreviewとProductionで保存先・認証情報を分けてください。環境変数変更後は再デプロイが必要です。

## 費用・AI処理・復旧

AIによる読み取り・相談・作問は従量料金が発生します。作成済みの問題の採点・復習にはAIを呼びません。現在の既定上限は全体の作問3回/日・10回/月、相談20回/日・100回/月です。プロフィール会話は本人ごとに8回/日・40回/月。招待登録でこれらの上限を増やすことはありません。件数上限は金額上限ではないため、AI提供元の利用上限も設定してください。

作問は1バッチ最大10問、目標1〜300問で、保存済みの問題から学べます。資料が不足する場合は水増しせず、目標より少なくなることがあります。最初の3問は試作で、本人がその案を確認して本作成を依頼します。新しい相談後に古い試作から本作成することはできません。

処理待ち画面は実際の処理段階を表示し、時間だけで進む架空の進度は使いません。別画面へ移っても本人の依頼の完了・失敗から元の学習プランへ戻れます。状況確認だけで有料処理を再送しません。失敗後の「同じ条件で続きを作る」は、既存問題を残して不足分だけを新たに依頼します。再依頼は利用回数に含み、失敗した呼び出しにも費用が発生する場合があります。

ElevenLabsを設定した場合、必要な英文の音声を生成し、同じ内容をDriveから再利用します。通常の新規音声は全体30件/日・300件/月、1件1500文字、計30000文字/日・150000文字/月。運営の固定教材準備には別の日次枠がありますが、月次上限を維持します。失敗・結果不明の生成を自動再試行しません。英語発音の明示的な再生と、回答時の効果音は別機能です。

### 節約モード（明示的な切り替えが必要）

`AI_MODEL_PROFILE` が未設定・空・`legacy` の場合は、従来どおり `ANTHROPIC_MODEL` を使い、本作成は1バッチ1回です。`economy` を設定した場合だけ、読み取りと本作成の下書きをHaiku 5.5、相談・3問の試作と本作成の検証をSonnet 5.5へ分けます。アプリ内から利用者がモデルを指定する仕組みではありません。AIの有効化、本人の承認、利用回数制限は従来のままです。

| 処理 | `economy` の既定モデル | 個別に上書きする環境変数 |
| --- | --- | --- |
| 写真・PDFの読み取り | `claude-haiku-5-5` | `ANTHROPIC_SOURCE_MODEL` |
| 本作成の下書き | `claude-haiku-5-5` | `ANTHROPIC_DRAFT_MODEL` |
| 相談・3問の試作 | `claude-sonnet-5-5` | `ANTHROPIC_PLANNING_MODEL` |
| 本作成の検証 | `claude-sonnet-5-5` | `ANTHROPIC_VERIFICATION_MODEL` |

優先順位は「個別の上書き → 明示した節約モードの既定値 → 従来の `ANTHROPIC_MODEL`」です。プロフィール会話は今回の節約対象に含めず、従来モデルを維持します。節約モードの5.5系には `effort=medium` を設定しますが、思考を無効化する設定ではありません。[effortの仕様](https://platform.claude.com/docs/en/build-with-claude/effort)を参照してください。5.5系の構造化出力はJSON Schema、旧モデルは従来の指定tool出力を使い、どちらもアプリ側の形式・根拠・単語問題の検査を通します。

本作成では最大10問ごとに、下書きと検証を別の呼び出しとして記録します。Sonnetには資料の読み取り結果・承認条件・全設問を渡し、不備の一覧だけを返させます。1問でも不備がある、全問分の確認がない、下書き自身が不確かとしている、根拠IDが今回の資料と一致しない場合は、そのバッチを保存せず停止します。自動修正・検証失敗時の自動再試行は行いません。既に保存済みの問題は残ります。

資料の読み取り結果は保存して再利用します。本作成・検証では、固定の教材と承認条件を先頭に置き、変化する問題数・出題済み語・既存問題を後ろに分けて5分の[プロンプトキャッシュ](https://platform.claude.com/docs/en/build-with-claude/prompt-caching)を要求します。資料の差し替え、時間切れ、提供元の最低トークン数などによりキャッシュされない場合があり、初回の書き込みにも料金がかかります。異なるモデルや検証用の指示との間で共有される前提にはしていません。

**削減率と教材の正確さは未評価です。** 実APIでの比較試験はまだ行っていません。検証が通っても、OCRが読み違えた語・欠けたページ・原本の解答まで正しいとは保証できません。試作と元の写真・PDFを照合してから本作成へ進めてください。モデルを分けるだけで費用が必ず5分の1になるわけではなく、検証の追加分も請求されます。

2026年10月24日確認の[公式料金](https://platform.claude.com/docs/en/about-claude/pricing)では、通常の入力／出力100万トークンあたり、Haiku 5.5は1呼び出しの入力が100,000トークン以下なら$0.10／$0.50、超える場合は$0.50／$2.50、Sonnet 5.5は$2／$10です。100,000は文字数や複数呼び出しの合計ではありません。

参考計算として、8資料の読み取りを入力16k・出力8k、試作を14k・2.5k、50問を5バッチとして各回固定入力12k・動的入力合計10k・出力合計18kと仮定すると、全処理Sonnet・キャッシュなしは約$0.485です。検証を各回固定入力12k・動的入力合計23k・出力合計1kとし、下書き・検証それぞれ初回にキャッシュを書き、残り4回が命中する節約モードは約$0.161です。この仮定では約3分の1であり、実測ではありません。思考トークン、失敗、再依頼、為替・税は含まず、実際の入力長とキャッシュ利用で増減します。運営画面の利用記録と提供元の請求で確認してください。待ち時間を許容する運営向けのBatch APIは将来の選択肢で、現在は未実装です。

## 本人専用のデータと保存範囲

- 写真は長辺2400px以内のJPEGへ調整してEXIFを含めず送信。PDFは1件10MB、1回20資料まで。HEIC非対応ブラウザではJPEGへの変更を案内します。
- Claudeへ送るのは選択した教材、目標・レベル・相談、必要な問題内容と学習成績の集計です。メールアドレスや生の回答履歴は送りません。
- 教材の読み取り結果を保存して再利用します。全教材横断のベクトル検索は未実装です。
- 学習用の未回答問題は正解・解説を隠し、採点はサーバーで行います。本人の一覧レビュー・編集や試作では正解を確認できます。
- 写真・問題・学習プラン・会話・回答・出題・練習セッションは、所有者・本人IDで絞ります。他人のIDを送っても取得・更新できません。
- 旧共有・公開・配布・ユーザープレビューのAPIは410で拒否します。旧パブリック問題は通常の学習へ表示しません。既に本人所有として保存済みの問題は維持します。
- 感想は入力した文章・分類・内部アカウントID・日時・版だけを記録します。1人1日5件まで、同じ送信の再試行は重複登録しません。
- 認証・AI・Google保存用の秘密情報はブラウザへ渡しません。教材APIには認証を要求し、Driveのリンク共有は不要です。
- 学習データをService Workerにキャッシュしません。オフラインでは接続の案内を表示します。
- 元のEventsタブを並べ替え・手動編集しないでください。運営用Googleアカウントのアクセス管理とバックアップも必要です。

教材の権利・利用条件を守って利用してください。個人利用に限定することだけで、すべての教材の保存・AI処理が許諾されるわけではありません。

## 公式指定と編集上の提案を分ける

| 種類 | 例 | 扱い |
| --- | --- | --- |
| 公式の範囲・履修条件 | 高校の必履修科目、理科の選択経路、中学理科の大項目の学年 | 本文・解説の該当項目へ結び付ける |
| 公式の内容の取扱い | 学習の深さ、選択する内容、原則の履修順 | 大項目の名前だけで省略しない |
| 編集上の分割・到達目標 | 1つの項目を複数の教材に分割、単元ID、学習者向け表現 | 文科省の直接指定と表示しない |
| 学年配当モデル | 高1に地理総合、高2に公共など | 学校の教育課程に応じて変更可能にする |
| 制作上の提案 | 試作3問、単元セット10問、作問順 | 学習指導要領が要求する分量とは扱わない |

## 教材を確定するときの確認

1. 本文の目標・内容・内容の取扱いを確認し、解説で範囲と例示を確認する。
2. 単元を採点可能な小目標に分け、各小目標に根拠の章節を持たせる。1行を1問に機械的変換しない。
3. 教科書との対応には採択教科書の書名・出版社・版・目次が別途必要。現時点では教科書準拠とは表示しない。
4. 入試対策を追加する場合は、該当年度・試験の公式出題範囲を別途確認する。学習指導要領への対応だけで入試全対応とは表示しない。
5. 社会統計、地名・国境の表現、制度、時事、科学の数値定数・測定条件は、それぞれの一次資料と基準日も持たせる。指導要領は最新統計そのものの出典ではない。
6. 図表・史料・写真・地図を追加するときは、素材ごとの利用条件と出典を記録する。教材本文と問題文は原則として新規に執筆する。
